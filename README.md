# Пульс — тренажёр данных и интеграций

Интерактивный тренажёр для системных аналитиков. Сквозной кейс — сеть фитнес-клубов «Пульс».

**Открыть:** https://andreypol1991.github.io/puls-trainer/

За 4 недели и 19 тренировок студент с нуля проходит путь:

- **Неделя 1.** Вопросы директору клуба и ИТ: выясняет требования сам.
- **Неделя 2.** Данные: концептуальная, логическая и физическая модели, нормализация, ограничения, нагрузка и репликация.
- **Неделя 3.** Интеграции: карта интеграций, REST, коды и ошибки, идемпотентность, гонки, лестница Ричардсона и HATEOAS, пагинация, HTTP-кэш, версии, ретраи, вебхуки, безопасность, GraphQL, gRPC, SOAP, SSE.
- **Неделя 4.** Сквозные сценарии, ночь инцидентов, защита решения.

Каждая тренировка: «1. Теория» — живые разделы «Как это работает», «2. Практика» — задания с проверкой и разбором.

Прогресс хранится в браузере. Отчёт для преподавателя — кнопка «Отчёт» вверху страницы.
